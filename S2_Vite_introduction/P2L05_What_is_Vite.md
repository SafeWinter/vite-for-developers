# P2L05：What is Vite?

---



## Vite 是什么

它是：

- 一款针对 `Web` 应用的构建工具；
  - 最核心功能：是速度极快（也是卖点）；
  - 为各大前端框架提供了强大的默认配置；
  - 定位：非单一的模块打包工具（`ESBuild` 打包 + `Rollup` 构建）
- 内置开发服务器，显著提升开发体验（开发、测试、重新加载页面并自动保留上下文）；
- `Vite` 是一款代码脚手架——
  - 为主流框架（`Vue`、`React`）提供大量模板代码；
  - 构建速度不受后期代码规模扩展的影响。
- 提供了强大的插件系统，既可按需安装现成的插件，也可以根据需求自行定制（后续课程详述）。
